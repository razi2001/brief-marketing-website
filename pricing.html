A few questions.

Why is self-hosted free?
You bring the agent, which means we don't pay for inference and you don't pay us. The extension is MIT licensed; source is on GitHub.
How is Cloud different?
Same captures, hosted backend. We file the tickets for you. Good if you'd rather not wire up an agent.
Will Cloud replace the open-source version?
No. Self-hosted stays free and open forever. Cloud is for teams who'd rather we run it.
