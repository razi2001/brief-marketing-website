A few questions.

Why is Brief Local free?
You bring the agent, which means we don't pay for inference and you don't pay us. The extension is MIT licensed; source is on GitHub.
How is Brief Cloud different?
Same extension, same capture — but when you hit stop, the brief uploads and a hosted agent writes the ticket and files it. No local agent, nothing to wire up. Good for PMs, sales, and support who see bugs but don't run coding agents.
Which trackers does Cloud support?
Linear today — connect it in two clicks. Jira is built and next in line. Brief Local already files anywhere your own agent can reach: Linear, Jira, GitHub Issues, Notion.
What happens to my recordings on Cloud?
They're uploaded to private storage, used once to write the ticket, embedded as evidence in the issue, and the source media is deleted once the ticket is filed. On Brief Local, nothing ever leaves your machine at all.
Will Cloud replace the open-source version?
No. Brief Local stays free and open forever. Cloud is for people who'd rather we run the agent.
