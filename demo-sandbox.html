🐞 Planted bugs (spoilers for the demo)
  1. Squished avatar: the top-right photo uses object-fit:fill, so it stretches.
  2. Unreadable help text: the grey hint lines fail colour-contrast (about 1.6:1).
  3. Mobile overflow: the two-column profile grid never collapses; on a phone the right column runs off-screen.
  4. Clipped plan pill: "Acme Professional (annual)" is cut off inside a fixed-width pill.
  5. Misaligned toggles: the notification switches sit lower than their labels.
  6. Dead checkbox: the "I understand…" box shows no checked state when you tick it.
  7. Overlapping buttons: on a phone the fixed-width "Save changes" button overflows and overlaps "Cancel".
  8. Broken save: clicking Save changes errors out (visible banner + console error + a failed PUT /api/account).
